# Sri Shankar Digitals – Personalised Gift Store

## Included
- Responsive gift catalogue website
- Product categories and add-to-cart flow
- Customer name, phone and personalisation notes
- WhatsApp order handoff to +91 94487 57499
- Basic installable PWA support for Android browsers
- Simple local product manager

## Important limitations of this free starter
1. It is a website/PWA, not a Play Store-published native Android app. Customers can open it in Chrome and use **Add to Home screen**.
2. The product manager stores additions in the browser/device where they were entered. It is not a shared online admin database.
3. Customer photos are not uploaded to a server. The order opens WhatsApp and asks the customer to attach the photo in the chat.
4. Prices are intentionally blank until you enter your actual prices.
5. Free hosting can be used with GitHub Pages. For PWA installation and service-worker support, use HTTPS hosting.

## Publish free using GitHub Pages
1. Sign in at https://github.com/ and create a new public repository, e.g. `sri-shankar-gift-store`.
2. Upload all four files: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/root`, then Save.
5. Wait for the published URL shown in Pages.
6. Open that URL on an Android phone in Chrome → menu ⋮ → **Add to Home screen** or **Install app**.
